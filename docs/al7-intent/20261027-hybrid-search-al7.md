Stage 2, substep 2a from CLAUDE.md: Hybrid search. A searchPlaces function that takes structured parameters: query text (required), optional spatial filter (centre point + radius in metres, or a bounding box), optional tag titles, and a result limit (default 20, max 50). It embeds the query text with Voyage voyage-4 (input_type "query", 1024-dim), then runs one SQL query: the PostGIS filter (ST_DWithin on the place centre point, or bbox intersection) and the tag filter restrict candidates, and pgvector cosine distance (<=>) ranks them using the HNSW index. Only places with an embedding are searchable. Each result: place id, name, Wikimapia link, tag titles, centre point, distance in metres from the centre when a radius was given, and similarity score. Results outside the spatial filter are never returned. Runnable for manual checks via tsx (e.g. `pnpm search "museum" --near 44.817,20.457 --radius 500`). Tests mock Voyage; database tests use the test DB with synthetic 1024-dim vectors.

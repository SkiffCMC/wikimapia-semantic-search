Stage 1, substep 4 from CLAUDE.md: Embeddings. Data from the first real crawl (80 detailed places, see "Crawled data profile" in CLAUDE.md) shows comments are nearly absent and descriptions are short (median 23 chars, many are only URLs), while every place has tags. So embed one "place document" per place: name, tag titles, address, description with bare URLs removed, and any comment messages, combined into one text. Embed with Voyage AI voyage-4 (1024-dim, input_type "document") via the voyageai npm package into a vector(1024) column added by a new migration, with an HNSW cosine index. Store a hash of the document text and the model name so unchanged places are skipped on re-runs. Batch up to the Voyage request limits, resumable, with a configurable per-run limit and a run summary (places embedded, skipped, failed, tokens used). Places with only summary data (no details yet) are skipped. Key from VOYAGE_API_KEY; add it and ANTHROPIC_API_KEY to .env.example. Runnable via tsx (e.g. `pnpm embed`). Tests mock the Voyage client; no live calls.
